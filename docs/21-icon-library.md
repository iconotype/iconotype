# 21 — The icon library

> Searching 230+ open icon sets from inside the app, and shipping their licences with
> the font.

Every project up to here started from artwork you already had: an IcoMoon export, a
folder of SVGs, a font file. Most real projects do not start that way. You want a
chevron and a trash can, and drawing either one is a worse use of an afternoon than
finding one somebody already drew.

## Why Iconify

The three libraries asked for — [Lucide](https://github.com/lucide-icons/lucide),
[Google's Material icons](https://github.com/google/material-design-icons), and
[Pictogrammers' MDI](https://pictogrammers.com/library/mdi/) — publish artwork, not
search. Each ships a repository or an npm package; none offers "find me every open icon
called *chevron*".

[Iconify](https://iconify.design)'s API does, for all three and 230+ more, as one index:

| | |
|---|---|
| collections | 236 |
| icons | 334,616 |
| CORS | `access-control-allow-origin: *` |
| caching | `public, max-age=604800, immutable` |
| auth | none |
| self-hosting | [`iconify/api`](https://github.com/iconify/api), same endpoints |

Critically it carries **licence and author per collection**, which is what makes
attribution automatic here rather than a thing you are trusted to remember.

The endpoints used, all verified against the live service:

```
GET /collections                        every collection, with licence + author
GET /collection?prefix=lucide           one collection's icon names, by category
GET /search?query=&limit=&prefixes=     full-text across every indexed collection
GET /lucide.json?icons=house,user       artwork: `body` + the box it was drawn in
```

`/{prefix}/{name}.svg` exists too and is **not** used: it emits `width="1em"
height="1em"`, which carries no absolute scale. The bundle endpoint gives real numbers
and the client rebuilds the `viewBox` from them.

## Stroke icons were the open question

Lucide and Tabler draw with `stroke="currentColor"` and `fill="none"`:

```html
<g fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round">
  <path d="M15 21v-8a1 1 0 0 0-1-1h-4a1 1 0 0 0-1 1v8"/>
  …
</g>
```

A font glyph has no stroke. Every contour is a filled outline, so a stroked icon has to
be **outlined** — the stroke converted into the shape it paints — before it can become
a glyph at all. This is stage 6 of the fixer ([04](04-svg-normalization.md)), and it is
the reason this feature is thirty lines of client rather than a project of its own:

```
lucide:house  → TRANSFORM_BAKED, STROKE_OUTLINED  → 1 path, 1024-unit em box
mdi:home      → TRANSFORM_BAKED                   → 1 path
```

Library artwork goes through `importSvg`, exactly like a file you dropped. No separate
path, no special-casing, and the visual regression corpus already covers the hard part.

## Attribution

Adding icons creates **one set per collection**, carrying that collection's licence,
author and a link to the terms. This is not tidiness: Lucide is ISC, MDI is Apache 2.0,
Font Awesome is CC BY 4.0. Merged into one set, no single licence statement is true of
it — and CC BY requires the credit to travel with the work.

From there the credit follows the artwork on its own:

- the glyph's `source` records licence, author, and a link back to the icon
- `.iconotype.json` rolls the set licences up into `credits`
- **the generated stylesheet prints them**, because that is the one file that always
  ships next to the font:

```css
/* demo v1.0 — generated by Iconotype. Do not edit by hand. */
/*
 * Artwork credits:
 * Lucide by Lucide Contributors — ISC https://github.com/lucide-icons/lucide/blob/main/LICENSE
 * Material Design Icons by Pictogrammers — Apache 2.0 https://…
 * Tabler Icons by Paweł Kuna — MIT https://…
 */
```

A round-trip bug fell out of writing that. The committed file is one flat set by design,
so reading it back gave the single set the **font's** name and the **first** credit —
and writing it out again turned `Lucide — ISC` into `demo — ISC` and dropped the other
two licences entirely. Silent, and for CC BY artwork not a cosmetic loss. `Project` now
carries a `credits` roll-up that survives the flattening, and it is the roll-up the
serializer trusts, not the sets.

## Where it is

- **App and web** — *Find icons…* in the toolbar, `⌘K`, or the empty-project screen
- **VSCode** — *Iconotype: Find Icons in Open Libraries…*, or the search button on the
  icon grid
- **CLI** —
  ```bash
  iconotype find chevron --prefixes lucide,tabler
  iconotype add lucide:house mdi:cog --input app.iconotype.json
  ```
  `find` prints `prefix:name`, which is exactly what `add` takes, so grep composes.

## What is sent

The search string and the icon names you pick. Nothing else — not the project, not its
icons, not the file path. `libraryHost` points the whole client at a self-hosted
`iconify/api` if even that is too much; the only catch is the CSP, which names
`https://api.iconify.design` explicitly in the Tauri config and the VSCode webview
policy rather than opening `connect-src` to `https:`. A different host needs its own
entry there.

## Four bugs worth recording

**Present-but-undefined options.** `importSvg(svg, name, { targetHeight: set?.height })`
on a set that did not exist yet spread `targetHeight: undefined` over the default 1024,
and every later stage multiplied by `NaN` until the path builder gave up with `Use a
moveTo() command first` — an error four stages downstream of the cause. `fixSvg` now
ignores keys whose value is `undefined`. Optional chaining produces exactly that shape,
so this was never hypothetical.

**A `<button>` will not size to its children.** The result cells were buttons laid out
with `display: grid`; Chrome wraps a button's children in one anonymous box and sized
the rows `32px 0 0` — artwork visible, both labels gone. They are now `<label>`s around
a checkbox, which is what a multi-select control actually is, so the selected state is
announced for free.

**Auto rows shrink to fit.** Ninety-six results in a fixed-height track had their rows
compressed to fit the box instead of overflowing it: every cell clipped to its artwork
and nothing to scroll. `grid-auto-rows: min-content` plus `min-height: 0`.

**`button:hover` outranks `.backdrop`.** The invisible click-catcher behind every modal
inherited the theme's accent hover, so moving the pointer off the dialog flashed the
whole window violet. The hover state has to be restated on the backdrop itself.

## Deliberately not done

- **Bundled offline sets.** `@iconify/json` is ~200 MB; per-collection packages would
  mean choosing collections at build time, which is the opposite of searching all of
  them.
- **A "browse this collection" mode.** `listCollection()` exists and is tested; nothing
  calls it yet. Search covers the case you actually have.
- **Grouping the add into one history step.** Adding across three collections is seven
  labelled steps (`set.add`, `glyph.add`, `codepoint.assign`, per collection). Each has
  an exact inverse, which is the property the history tree is built on; collapsing them
  needs a transaction in the model, not a change here.
